## Français

```
JellyGlass 2.7.0

• Une interface plus vivante : le cœur et « Vu » réagissent quand vous les touchez, les affiches apparaissent en fondu, la fiche glisse sous son image quand vous la faites défiler, et les boutons du lecteur s'animent
• Le mode clair plus lisible : les grandes images en haut des pages ne sont plus délavées, et leur texte s'adapte à l'image
• Si une vidéo ne peut vraiment plus repartir, JellyGlass affiche « Lecture impossible » au lieu de rester sur une image figée
• Seerr pour l'admin* : dès la première connexion, vous et les profils déjà autorisés dans Seerr pouvez faire des demandes. « Synchroniser depuis Seerr », dans « Qui peut demander », reprend les droits de chaque profil
• Une adresse saisie sans « http:// » trouve aussi un serveur installé chez vous
• Corrections de bugs

* Nécessite un serveur Seerr

Merci d'utiliser JellyGlass. Rapports de bugs et suggestions : https://github.com/b-raillard/Cinemax/issues
```

## English

```
JellyGlass 2.7.0

• A livelier interface: the heart and "Watched" react when you tap them, posters fade in, a title's page slides under its picture as you scroll, and the player's buttons come alive
• Clearer light mode: the large pictures at the top of pages are no longer washed out, and their text adapts to the picture
• If a video truly cannot restart, JellyGlass says "Couldn't play this video" instead of sitting on a frozen picture
• Seerr for admins*: from the first connection, you and the profiles Seerr already allows can make requests. "Sync from Seerr", in "Who can request", copies each profile's rights from Seerr
• An address typed without "http://" also finds a server running at home
• Bug fixes

* Requires a Seerr server

Thanks for using JellyGlass. Bug reports and suggestions: https://github.com/b-raillard/Cinemax/issues
```
