## Français

```
JellyGlass 2.5.0

• Gestion multi-comptes : « Qui regarde ? » garde le profil, les reprises et les réglages de chacun sur le même appareil, avec un code facultatif par compte
• « Reprendre ici » : un film en cours sur un autre appareil se relance ici à la même seconde, et l'autre appareil s'arrête
• Douze nouvelles icônes au choix, trois éditions Halloween et neuf couleurs (Réglages → Apparence)
• Le thème Halloween quand vous voulez : Automatique, Désactivé ou Halloween
• Corrections de bugs

Merci d'utiliser JellyGlass. Rapports de bugs et suggestions : https://github.com/b-raillard/Cinemax/issues
```

## English

```
JellyGlass 2.5.0

• Multi-account support: "Who's watching?" keeps each person's profile, progress and settings on the same device, with an optional code per account
• "Resume here": a film playing on another device picks up here at the same second, and the other device stops
• Twelve new icons to choose from, three Halloween editions and nine colours (Settings → Appearance)
• The Halloween theme whenever you like: Automatic, Off or Halloween
• Bug fixes

Thanks for using JellyGlass. Bug reports and suggestions: https://github.com/b-raillard/Cinemax/issues
```
